# Deploy Orthobitto v4.0 to Vercel

Upload the flat release folder to a GitHub repository and deploy the repository as a static site on Vercel. Keep `sw.js` and `manifest.json` at the site root so the PWA scope remains the root.

After deployment, verify HTTPS, camera permission, image upload, OCR, local dictionary lookup, theme switching, service-worker update, PDF export and mobile Safari/Chrome behavior.
