# Orthobitto v4.0 — Product Architecture Release

## Locked scope implemented
- System / Light / Dark theme preference with OS sync.
- Quiet-luxury non-blue visual system.
- Direct word tap → Word Card.
- Part-of-speech / pronunciation / meaning / context / examples / save / practice hooks.
- IndexedDB learning store for saved words and mastery metadata.
- Learn / Saved / More hub.
- Reading Mode.
- Four-corner perspective crop with client-side projective transform.
- Existing OCR, camera, upload, translation, local approved dictionary and PDF export preserved.
- Dictionary architecture remains local-first and merge-ready for future vocabulary batches.
- Service-worker versioning aligned to v4.0.2.

## Important QA note
The release was statically validated in the build environment. Real iPhone/Android device/browser testing is still required for final hardware-level verification.
