# GitHub upload guide

This ZIP is prepared so that its contents can be placed directly at the repository root.

Recommended path:

1. Extract the ZIP.
2. Open the extracted folder.
3. Select all files inside that folder.
4. Upload those files to the root of the GitHub repository, or push them with Git/GitHub Desktop.

Do **not** upload the ZIP as the repository source itself; GitHub will store a ZIP as a single binary file rather than unpacking it into the repository.
