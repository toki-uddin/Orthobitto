# Orthobitto v4.0.2

Theme and branding refinement release.

- System appearance is represented by a premium gear/settings icon.
- Light appearance uses a sun icon.
- Dark appearance uses a moon icon.
- Theme selection is compact, keyboard accessible, and persisted.
- System mode follows `prefers-color-scheme` and reacts to OS/browser changes.
- UI typography upgraded to Manrope + Noto Sans Bengali.
- Orthobitto wordmark now uses theme-aware high-contrast gradients.
- App icon and favicon now use a circular black/champagne mark without the previous blue rounded-square surround.
- Existing OCR, crop, dictionary, Word Card, learning and offline features remain part of the release.
