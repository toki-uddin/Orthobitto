# Orthobitto v4.0.5 — Favicon Alignment

The browser favicon, Apple touch icon, PWA icons, header icon, and launcher assets are all regenerated from the same master `icon-512.png` asset.

The previous alternate `favicon.svg` mark was removed from active references to prevent a different logo from appearing in the browser tab. `favicon.ico`, `favicon-16.png`, and `favicon-32.png` now use the same Orthobitto circular black/champagne logo as the header.
