# Orthobitto v4.0 upload notes

The release is intentionally flat: production files live at the repository root.

Required first-run checks:
1. Open the site over HTTPS.
2. Allow camera access when requested.
3. Test upload and scan.
4. Tap an OCR word and confirm the Word Card opens immediately.
5. Verify System / Light / Dark theme behavior.
6. Install as a PWA and retest camera/upload.

Future vocabulary batches can be merged into the versioned approved dictionary without changing the UI contract.
